# Contributing

Contributions that make planned network changes safer, clearer, and easier to validate are welcome.

## Ways to contribute

- Suggest a template, checklist, or validation workflow.
- Report an error, ambiguity, or missing rollback consideration.
- Improve documentation or examples.
- Submit a pull request for a focused improvement.

## Before opening a pull request

- Keep changes vendor-neutral unless the folder or filename makes the vendor scope explicit.
- Do not include customer data, real IP addresses, credentials, configuration exports, or confidential change records.
- Explain the practical problem your change solves.
- Keep templates clear enough to use during a production change window.

## Issues

When raising an issue, include:

- What you were trying to achieve
- What was unclear or missing
- Your suggested improvement, if you have one
- Any relevant environment or workflow context, with sensitive details removed

## Security issues

Do not report vulnerabilities through public issues. See [SECURITY.md](SECURITY.md).
